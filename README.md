One emoji for make.fun's "One Emoji, One Dream Vacation" bounty. The program writes exactly one emoji to `/output/entry.txt`: 🗻 Mount Fuji (U+1F5FB) — a single code point, 4 bytes UTF-8, no trailing newline.

> 🗻

Why Fuji: it plainly names a dream vacation (an iconic mountain), reads as a postcard at a glance, and points at one particular dream — Japan, one mountain — instead of any generic beach holiday, while staying instantly readable at any size.

## Run it

```sh
node main.ts
```
